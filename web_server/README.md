# Web Server - System Engineering & DevOps

This directory contains configuration scripts and automation files for setting up and managing an Nginx web server on Ubuntu 16.04 LTS as part of the ALU Software Development program.

## Files
* `0-transfer_file`: Bash script to securely transfer a file to a remote server via SCP.
* `1-install_nginx_web_server`: Bash script to install and configure Nginx.
* `2-setup_a_domain_name`: Contains the configured domain name (`honoreideas.tech`).
* `3-redirection`: Bash script to configure a 301 HTTP redirection on Nginx.
* `4-not_found_page_404`: Bash script to configure a custom 404 error page.
* `5-design_a_beautiful_404_page.html`: A creative, custom HTML 404 error page.
